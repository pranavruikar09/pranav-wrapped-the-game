# Pranav Wrapped: The Game

Create a premium, highly interactive personal Creative CV website called:

"PRANAV WRAPPED — THE CHESS EDITION"

This is a creative CV for a L'Oréal selection process. It must NOT feel like a conventional résumé, corporate portfolio, recruitment website, or professional case-study presentation.

The purpose is to let the viewer understand the PERSON behind the résumé: personality, passions, worldview, relationship with beauty, a L'Oréal brand he relates to, strengths, weaknesses, memories and quirks.

The core creative concept is:

SPOTIFY WRAPPED × CHESS × PERSONAL STORY

Spotify Wrapped provides the visual language:

- Full-screen storytelling

- Large typography

- Bold cards

- Statistics

- Playful microcopy

- Smooth transitions

- "Most played", "Top genres", "Current mood", "Biggest plot twist" style sections

- A sense of discovering someone's personality

Chess provides the narrative:

- Opening

- Development

- Attack

- Blunder

- Sacrifice

- Endgame

- The chessboard should gradually evolve throughout the experience

- Chess should be a meaningful metaphor, NOT a gimmick

Personal photography provides authenticity:

- Use a small number of real photographs

- Do NOT assume there are many photographs

- Do NOT generate fake personal photos

- Use placeholders for photos that can easily be replaced

- The lack of photographs can itself become a small personality detail

IMPORTANT:

Do not invent personal facts, hobbies, opinions, memories, weaknesses, beauty beliefs, L'Oréal brand preferences or life experiences.

Use clearly marked editable placeholder content wherever personal information is required.

OVERALL EXPERIENCE

The website should feel like an interactive digital story rather than a website.

There should be no conventional navigation bar such as:

Home | About | Experience | Contact

Instead, the user should enter an immersive story.

Opening screen:

A minimalist chessboard in the center of the screen.

Text:

"EVERY GAME STARTS WITH A POSITION."

Then:

"So does every life."

Then:

"The interesting part is what you do with the next move."

Then a large CTA:

"▶ START GAME"

Below it, subtly:

"PRANAV WRAPPED · 2026"

When the user clicks START GAME, begin the experience.

Use smooth transitions and subtle chess-piece movement.

Chess chapter:

"OPENING"

Title:

"MEET THE PLAYER"

Subtitle:

"Before the moves, there was the player."

This section should answer:

- Who is Pranav?

- What is his personality?

- What makes him different?

- A short introduction in his own voice

Use one main portrait placeholder.

Create Spotify-style personality cards:

"YOUR TOP TRAITS"

3. [TRAIT]

4. [TRAIT]

5. [TRAIT]

Then:

"MOST LIKELY TO"

[PERSONAL QUIRK]

[SHORT PERSONAL DESCRIPTION]

Keep everything concise.

Chess chapter:

"DEVELOPMENT"

Title:

"WHAT I PLAY WHEN NOBODY IS WATCHING"

Do NOT present hobbies as a boring list.

[Why I enjoy it]

"YOUR MOST PLAYED"

[PASSION]

[INTEREST]

[THING]

The tone should be playful and honest.

SECTION 03 — THE COMPETITIVE SIDE

Chess chapter:

"ATTACK"

Title:

"I LIKE COMPETING."

But do not make this a résumé achievement section.

Explore WHY the person likes competition.

Create a visual scale:

"WHY I COMPETE"

Winning ←——————→ Getting Better

Include a few small Spotify-style statistics:

"FAVOURITE FEELING"

[TEXT]

"LESSON LEARNED"

[TEXT]

The point is to reveal personality, not achievements.

SECTION 04 — WHAT BEAUTY MEANS TO ME

This must be a major section.

Do NOT use generic corporate statements such as:

"Beauty is confidence."

"Beauty is self-expression."

"Beauty is about feeling good."

Instead create a personal, reflective storytelling section.

Title:

"BEAUTY, ACCORDING TO PRANAV"

Start with:

"I USED TO THINK..."

[PERSONAL VIEW]

Then transition:

"NOW I THINK..."

[PERSONAL VIEW]

Then create 3 visual concepts representing the user's personal definition of beauty.

Possible structure:

BEAUTY = [CONCEPT 1]

[PERSONAL EXPLANATION]

BEAUTY = [CONCEPT 2]

[PERSONAL EXPLANATION]

BEAUTY = [CONCEPT 3]

[PERSONAL EXPLANATION]

Allow text to be replaced easily.

Visually, this section should feel more elegant and emotional than the playful Spotify sections.

Use subtle beauty-inspired abstract visuals, but do NOT turn the website into a cosmetics advertisement.

SECTION 05 — MY L'ORÉAL MATCH

Title:

"IF I WERE A L'ORÉAL BRAND..."

Then reveal:

"[BRAND NAME]"

This section should answer:

Do not write generic corporate reasons.

Create three personal connection cards:

"WHY #1"

[PERSONAL CONNECTION]

"WHY #2"

[PERSONAL CONNECTION]

[PERSONAL CONNECTION]

Then add:

"BUT WE'RE NOT IDENTICAL."

[HONEST DIFFERENCE BETWEEN THE USER AND THE BRAND]

This last section is important because it prevents the answer from sounding like flattery.

Use the selected brand's visual identity carefully, but keep the overall site identity consistent.

"BLUNDER"

Title:

"NOBODY PLAYS A PERFECT GAME."

Then:

"MY MOST REPEATED BLUNDER"

[REAL WEAKNESS]

Structure:

[REFLECTION]

[REAL CONSEQUENCE]

[WHAT I'M DOING ABOUT IT]

Do NOT use cliché weaknesses such as:

- I'm a perfectionist

- I work too hard

- I care too much

unless the user genuinely means them and explains them honestly.

Include a second smaller weakness if appropriate.

One weakness can be:

"I barely take photographs of myself."

Treat this lightly but thoughtfully:

"Apparently, I've spent years documenting things I found interesting and almost no time documenting myself."

Then explain what this says about the person.

Chessboard returns.

"But I know I want to keep playing."

Then:

"THANKS FOR PLAYING. ♟"

Add a subtle restart button:

"PLAY AGAIN"

INTERACTION DESIGN

The experience should include:

1. Smooth vertical scrolling

2. Full-screen sections

3. Subtle parallax

4. Chess pieces moving between sections

5. Cards appearing progressively

6. Text reveal animations

7. Number counters for statistics

8. Elegant page transitions

9. Hover interactions

10. Optional sound toggle

11. Progress indicator showing the current "move"

The progress indicator could show:

OPENING → DEVELOPMENT → ATTACK → BLUNDER → SACRIFICE → ENDGAME

As the user scrolls, the current chapter becomes highlighted.

CHESSBOARD INTERACTION

Create a persistent or recurring chessboard visual.

At the beginning:

All pieces are in starting position.

As the viewer moves through the story:

Subtle pieces move.

Do NOT make the user actually play a difficult chess game.

The chessboard is a storytelling device.

Potentially allow the user to click certain pieces to reveal small "Easter egg" personality facts.

Example:

Click Knight:

"YOU FOUND THE KNIGHT."

[PERSONAL FUN FACT]

Click Pawn:

"Most important things started small."

[PERSONAL STORY]

Click Queen:

"Everyone clicks the queen first."

[PERSONAL JOKE]

These should be editable placeholders.

VISUAL STYLE

The visual direction should be:

- Premium

- Minimal

- Editorial

- Youthful

- Intelligent

- Playful

- Personal

- Slightly experimental

Avoid:

- Corporate blue

- Generic résumé templates

- Excessive gradients

- Stock photography

- Generic AI-generated people

- Excessive icons

- Corporate charts

- Dense paragraphs

- "Professional portfolio" aesthetics

COLOR PALETTE

Base:

- Deep black / charcoal

- Off-white

- Warm cream

Accent:

Use one bold accent inspired by Spotify-style energetic visual design, but do not simply copy Spotify's green.

Potential accent:

Electric lime / vivid green OR deep purple OR warm red.

Use the accent sparingly.

Typography:

Use a bold contemporary display font for major headings and a clean sans-serif for body text.

Large typography is important.

Think:

"editorial magazine × digital product × Spotify Wrapped × chess."

RESPONSIVE DESIGN

Desktop is the primary experience.

It must also work beautifully on mobile.

On mobile:

- Chessboard scales down

- Cards become vertical

- Horizontal elements become swipeable

- No tiny text

- Animations remain smooth

PHOTO HANDLING

Create clearly marked photo placeholders.

For example:

[PHOTO — PORTRAIT]

[PHOTO — CHESS]

[PHOTO — FRIENDS / TEAM]

[PHOTO — PERSONAL MEMORY]

Make it very easy to replace these images.

Do not use generated faces or stock photos pretending to be the user.

CONTENT PRINCIPLES

The website should feel:

"honest > impressive"

"personal > professional"

"reflective > polished"

"human > perfect"

"story > résumé"

The viewer should finish thinking:

"I actually know this person a little better."

not:

"This is a very creative résumé."

TECHNICAL REQUIREMENTS

Build this as a real working website, not a static mockup.

Use clean component-based architecture.

Use CSS animations and lightweight JavaScript.

Prioritize performance.

No unnecessary libraries.

Make all personal content easy to edit from one central content/data file.

Use placeholder variables such as:

name

age

intro

traits

passions

beauty_definition

loreal_brand

brand_reasons

strengths

weaknesses

memories

fun_facts

stats

Make the structure easy for me to populate later.

Include a subtle loading animation.

Include a progress indicator.

Include a sound toggle, OFF by default.

Include a "Replay" button at the end.

Most importantly:

DO NOT INVENT MY PERSONAL STORY.

Build the complete visual and interaction framework with thoughtful placeholder content where personal information is unknown.

The website should feel like a beautifully designed interactive personal story that happens to be submitted as a Creative CV.
